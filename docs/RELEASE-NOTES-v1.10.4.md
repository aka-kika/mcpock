# mcpock v1.10.4

**2026-10-14** — The keyboard works on the Agents tab.

macOS 26+, Apple Silicon.

- **Arrow keys on the Agents tab.** Up and Down move through the agents,
  and through the servers of the one that is open. Right or Return opens an
  agent, Left closes it again. Before, the arrows did nothing there until
  you opened an agent with the mouse, so Control-Option-M then the arrows
  only worked on the Servers tab.

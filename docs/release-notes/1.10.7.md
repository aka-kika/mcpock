mcpock 1.10.7, 2026-10-17. For macOS 26 or newer on Apple Silicon. Update from the app, or download it from mcpock.com.

New in 1.10.7
- **Needs Wake open:** a server that belongs to a Mac app (like Wake, Vera or Kartina) no longer reads broken while that app is closed. It shows a calm grey dash and is checked again as soon as the app opens.
- **What's new:** this window, once after each update. It is in the right-click menu too.

Fixes in 1.10.7
- **Hidden servers come back while broken:** a hidden server that breaks shows in the panel until it works again, and the menu bar icon matches the panel.
- **Safer scan:** a file with a bare list of servers counts only when its name says it is an MCP config.
- **Cleaner checks:** a launcher's leftover child processes are stopped, and very long error output is capped.
- **More configs read:** .jsonc files with comments and trailing commas, and TOML files saved with Windows line endings.
- **More masking:** user names inside URLs and URL values in env settings are hidden in everything you copy.
- **Own keys per agent:** the same server with its own key in each agent no longer reads "set up differently".
- **Steadier checks:** a row's Check again no longer cancels a timer round, old results are never shown, and reading the configs is part of the same check.
- **Status file and widgets:** they count only the servers the panel lists.
- **Needs you:** it no longer stays selected after everything recovered.
- **Right-click menu:** it works from launch, before the first left-click.
- **Usage:** a dash until counts exist, turning Usage on counts at once, a call name always keeps its tool, and a history file rewritten in pieces never counts old calls twice.
- **Remote servers:** an old-style SSE address that sends no endpoint falls back to Streamable HTTP, and an answer counts only when it answers mcpock's own request.
- **Server PATH:** a server's own PATH comes first when mcpock starts it.
- **Glass theme:** a click on the menu bar item closes a panel opened with Control-Option-M.
- **Smoother panel:** finding which app a server belongs to runs in the background, so the panel never freezes during a check.

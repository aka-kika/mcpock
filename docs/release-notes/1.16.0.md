mcpock 1.16.0. For macOS 26 or newer on Apple Silicon. Update from the app, or download it from mcpock.com.

New in 1.16.0
- **Agents ask, you decide:** an agent can ask you to hide or show a tool, or to turn a server off or on, with a short reason. It changes nothing by itself. The ask shows on the server's card with **Yes** and **No**, a small dot on the menu bar icon, and one Mac notification (no sound). Yes opens the usual sheet with the agent's reason on top: you see every file before anything is written. No changes nothing. An ask you don't answer ends after one day.
- **The agent hears back:** it tells you in its chat that it asked, and later reads your answer (yes, no, or ended) with `mcpock_switches`.
- **Agents see which tools you use:** `mcpock_server` lists each tool's calls in your Usage window and when it was last used, and how many were not used, the same numbers the card shows. Only with Usage counts on.

For agents
- New tool `mcpock_ask` (server, tool, action, reason). It only leaves a request in mcpock's own folder; it never edits a config. The other four tools only read, as before.

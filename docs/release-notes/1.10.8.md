mcpock 1.10.8, 2026-10-17. For macOS 26 or newer on Apple Silicon. Update from the app, or download it from mcpock.com.

Fixes in 1.10.8
- **Servers with a startup message:** a server that prints a line before it starts (a banner, a settings note) no longer reads broken or slow, also when it answers in Content-Length frames.
- **No runaway memory:** a server that prints text starting with "Content" can no longer make mcpock grow until it crashes.
- **Switched-off servers stay off:** servers turned off in their agent (`"disabled": true`, or turned off in a Claude Code project) are no longer started.
- **Moved project folders:** a server whose project folder was deleted no longer fails to start.
- **Lighter on your Mac:** stopping a check no longer runs the processor flat out for a moment, and a launcher that exits at once leaves no processes behind.
- **Streamed answers:** a remote server that answers on a stream it keeps open no longer times out.
- **Sign-in servers rest:** a server that needs sign-in stays amber but is checked less often (5 min, 15 min, then hourly) instead of every minute.
- **Needs <App> open, only when true:** Xcode's tools and files inside an app no longer count as "needs the app", and a port an app used before is forgotten once a plain server answers on it.
- **Cursor usage:** a call Cursor rewrites later is no longer counted twice.
- **Usage across clock changes:** days are counted by date, so two days never merge into one where clocks move forward.
- **Copy All and Export:** Settings gives the same report your agents read, with config file paths and servers set up differently, and without hidden servers.
- **Header helpers:** a Claude Code headersHelper gets the server's own settings and runs in its project folder.
- **Mark as intended:** marking again replaces an agent's old setup, and the note comes back when the other agents move to a new setup.
- **Settings > Connect:** an mcpock entry that is switched off reads "Turned off" instead of Connected, and OpenCode's opencode.jsonc is read.

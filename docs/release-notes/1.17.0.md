mcpock 1.17.0. For macOS 26 or newer on Apple Silicon. Update from the app, or download it from mcpock.com.

New in 1.17.0
- **A check never opens an app:** a server whose command is a Mac app's own program (like Native Screen, run as "Native Screen --mcp") opened that app at every check, even right after you quit it. Now, while the app is closed, mcpock does not start it: the row reads "Needs Native Screen open" and is checked again as soon as you open the app. Helpers an app ships beside it run without the app and are checked as before.
- **Numbers with words:** every server row says what its numbers are, "24 tools · 130 calls", the same on the Servers and Agents tabs. Before, Servers showed a bare tool count and Agents a bare call count.
- **Hidden tools counted:** when tools are hidden, the row says "70/100 tools" (70 on, of 100). On an agent's row it counts what that agent hides; on the Servers tab, what every agent that can hide tools hides.
- **Codex / ChatGPT desktop:** the ChatGPT desktop app reads the same ~/.codex/config.toml, so the row names both.
- **New icon:** a switch, set to on, with mcpock's red knob. On a dark Mac it turns dark too.
- **The Hide sheet is one piece:** the Cancel and Hide bar no longer sits on a white stripe under the glass.

mcpock 1.18.0. For macOS 26 or newer on Apple Silicon. Update from the app, or download it from mcpock.com.

New in 1.18.0
- **A calm top:** three tiles under the tabs, on both tabs: servers in use, tools turned off, and what needs you. The middle one says how many of all ("149/388"); with nothing to do, the third is a quiet 0 with "all fine" under it. The footer now says when mcpock last checked.
- **One value per row:** a server row reads "5/7 tools", or "7 tools" when none is hidden; an agent's row reads "21/29 servers". Agent rows are one line, with no bar. The calls moved to the tooltip, the card, and an open agent's first line.
- **A new icon and menu bar mark:** the app icon and the menu bar now show the same thing, three stacked server units. The icon has its own dark and tinted looks, which the Dock shows when your Mac's icon style is set to them; About and What's New show the dark one in a dark window. The menu bar keeps the ring and the diamond when something needs you.
- **An icon for every server:** well-known servers get their own mono icon, the rest mcpock's plain server mark. To give a server your own picture, put a file named like it (`my-server.svg`, `.pdf` or `.png`) in `~/Library/Application Support/mcpock/ServerIcons/`. A fine server shows no dot; a small mark on the icon says when one needs you, is off, or is not checked. A broken server that never gave its tools reads "No tools".
- **The panel opens on Agents,** every time.
- **Claude account connectors:** turn on "Include claude.ai connectors" in Settings > Agents and they get their own section under the agents, with what Claude Code says about each: connected, not answering, needs sign-in, or off in a project, and how many times Claude Code called it. mcpock asks Claude Code for its list at most every 30 minutes, and Claude Code starts its servers to answer, so this is off until you want it.
- **Agents managed online:** Grok web, ChatGPT, Cursor cloud and Gemini keep their servers on their own sites, where mcpock can't check them. Each gets a row that opens its page; type their server names in Settings > Agents if you want them listed.
- **More switches:** servers can now be turned off and on in Cline, VS Code, Windsurf and Hermes profiles. Cline has its own setting for it; VS Code and Windsurf have none, so the entry waits in mcpock's own folder while it is off, as with Cursor. Turned on again, an entry goes back to the same place in its file, not to the end. The card also says when a Claude Code project has a server off ("Off in one project: shop").
- **A filter for agents that can't hide single tools:** Cursor, Claude Desktop, VS Code, Cline and Windsurf. The card offers it with one button: the agent then starts mcpock's small helper, the helper starts the server and leaves out the tools you turn off. Nothing else about the server changes, and Remove puts the entry back. For servers that run as a command; remove the filter before you delete mcpock.
- **New widgets:** the status widget is a ring of all your servers, with a sliver for each one that needs you. The Agents widget is a ring per agent with its logo inside, in medium and small. The grey text is easier to read on a light desktop.
- **The card says how many tools are on:** "Tools · 5/7 on".

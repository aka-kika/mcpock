mcpock 1.17.1. For macOS 26 or newer on Apple Silicon. Update from the app, or download it from mcpock.com.

New in 1.17.1
- **Just the numbers:** a server row reads "9/54 · 74": 9 of its 54 tools are on, and it had 74 calls. When no tool is hidden it is one number, "6". The calls sit after a dot in a lighter grey, so the two never run together. Hover the numbers for the words.
- **Agents count the same way:** an agent's row reads "21/29 · 3.1k": 21 of its 29 servers are on, and its own calls. An open agent shows the same at the top. Agents that keep no record of calls (Goose, Claude Desktop, OpenCode, Codex) show the first number only.
- **Fewer words on agent rows:** "8 off" and "All fine" are gone, because the numbers already say it. A word still shows when something needs you, like "1 not checked" or "2 need you".

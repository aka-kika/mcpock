mcpock 1.15.1. For macOS 26 or newer on Apple Silicon. Update from the app, or download it from mcpock.com.

New in 1.15.1
- **One switch for all agents:** on a server's card, "All 5" with a switch sits above the agents' own switches. It replaces the Turn off everywhere button and opens the same sheet first.
- **Easier to read in light mode:** the "Off in new sessions" lines are calm gray instead of amber, and the card's headings and file paths are darker, so they read on glass.

Fixed in 1.15.1
- **A slow server can't stop the checks:** an HTTP server that answered with an event stream and then sent a line with no end held every check until mcpock was quit. Now it stops at the check's time limit, like any slow answer.
- **Turning on a paused server:** its card no longer says off until you press Refresh.
- **Codex tool hiding:** works for servers that have an `env` or `http_headers` table in Codex's config.
- **Goose tool hiding:** hides only the tools you picked, even when Goose's copy of the server has tools the other agents' copies don't.
- **Goose and Hermes lists:** read and changed when the agent wrote them as one item per line.
- **OpenCode:** a config in OpenCode's older layout is left alone, with a note on the sheet, instead of getting a setting only newer OpenCode reads.
- **Turned-off entries from early 1.14 test builds:** can be turned on again.
- **Safer writes:** the switch's temporary file and backup are readable only by you from their first byte, and a leftover from an interrupted write is cleaned up. mcpock's folder of parked servers is never started over: if it can't be read, the switch stops and says so.
- **Config comments stay:** removing the first entry of a list no longer takes the comment above the next one.
- **Counts:** the footer counts a server once, and Claude Code calls are counted again after a session file was emptied and refilled.
- **No "..." in buttons and menus.**

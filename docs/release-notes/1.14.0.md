mcpock 1.14.0. For macOS 26 or newer on Apple Silicon. Update from the app, or download it from mcpock.com.

New in 1.14.0
- **Turn a server on or off:** open a server's card and flip the switch beside an agent, or press **Turn off everywhere**. Off means that agent does not start the server next time. On puts it back as it was: nothing is deleted.
- **You see it first:** a sheet says what happens in each agent and when it counts ("Off in new sessions", "Cursor is open: off after it reopens"), with the exact lines one click away. Nothing is written until you press Turn Off or Turn On.
- **A backup every time:** the file is copied to `~/Library/Application Support/mcpock/backups/` before it is changed, and replaced in one step. A file that changed while the sheet was open is not written.
- **Each agent's own way:** Claude Code's blocked list, the `enabled` line in Codex, Grok, Goose and Hermes, `enabled` or `disabled` in OpenCode. Cursor has no such line, so the entry is parked in the same file under `_mcpock_disabled`, keys and all. Claude Desktop has none either and removes what it does not know from its file, so there the entry waits in mcpock's own folder (`~/Library/Application Support/mcpock/parked/`, readable only by you) and moves back when you turn it on. Both were checked against the real apps.
- **Turned off, not gone:** a server that is off in every agent sits behind one line at the end of the list, **Turned off**. One that is off in some agents says so quietly ("Off in Cursor"). Servers you switched off in an agent yourself show there too, where mcpock used to leave them out.
- **For agents:** a new read-only tool, `mcpock_switches`, says what is off and where. Agents can't flip a switch: only you can, in the app.

What changed in the promise
- mcpock used to say it never changes your configs. From this version it changes one **only when you flip a switch**. It shows you the change first and keeps a backup. Everything else still only reads.

Not yet
- No switch for VS Code, Windsurf, Cline, Gemini CLI and files only the scan found: mcpock shows them and says so on the sheet.
- A server Claude Code has off in one project only (its own `/mcp` list) is left to Claude Code.

mcpock 1.15.0. For macOS 26 or newer on Apple Silicon. Update from the app, or download it from mcpock.com.

New in 1.15.0
- **Hide single tools:** open a server's card and flip the switch beside a tool. The tool is not deleted: your agents just stop seeing it, so it takes no room in their chats. Flip it back and they see it again.
- **See which tools you use:** with Usage counts on, each tool shows how many times your agents called it in the Usage window and when they last did. The most used come first. The ones not used in that time are folded together, with one **Hide all** button. Hidden tools sit in their own fold, with **Show all**.
- **Every agent, untick to keep:** the sheet lists each agent that has the server, all ticked. Untick one to leave it as it is. Nothing is written until you press Hide or Show, and every file is backed up first, as with the server switch.
- **Each agent's own setting:** Claude Code's deny list, `disabled_tools` in Codex, Grok's `disabled_mcp_tools`, `tools: exclude` in Hermes, a deny rule in OpenCode's permissions. Goose only keeps a list of the tools it may use, so a tool the server adds later stays hidden in Goose until you show it; the sheet says so. Show everything again and each file is exactly as it was.
- **For agents:** `mcpock_switches` and `mcpock_server` now say which tools are hidden, and where. Agents still can't change anything.

Not yet
- Cursor and Claude Desktop have no setting for hiding a single tool. Their row says so; use their own tool list, or turn the whole server off there.
- Counts per tool come from the agents mcpock reads usage from (Claude Code, Grok, Cursor, Hermes). A tool another agent uses can show as not used.

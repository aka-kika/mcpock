mcpock 1.11.0. For macOS 26 or newer on Apple Silicon. Update from the app, or download it from mcpock.com.

New in 1.11.0
- **Same setup as your terminal:** mcpock reads your login shell's PATH and keys once at launch, so servers installed with nvm, fnm, volta, mise or bun, and `${VAR}` keys from your shell, check like they do in your agent.
- **Allow this file:** a server from a file only the scan found waits until you choose Allow this file. Pause and Resume never approve a file, and a file that changes its commands later asks again.
- **Signed in by the agent:** a remote server you signed in to inside your agent (OAuth) shows a calm dash instead of Needs sign-in forever.
- **Quit in sight:** the gear in the panel's footer opens Settings, Check for Updates, What's New and Quit.
- **Check again on the row:** a row that needs you shows Check again under the pointer, and the card's button says its name.
- **First launch:** the panel opens once and says where mcpock lives.

Safer checks
- **Project .mcp.json files:** Claude Code's "enable all project servers" setting counts only in a folder Claude Code trusts.
- **Keys stay hidden:** keys in a server's own URL and in a server's reply are masked everywhere, and plain values like a region name no longer are.
- **Plain http warning:** a server that gets your keys over plain http from another machine says so on its card.
- **Private files:** the status and usage files are readable by you only.
- **aka:** mcpock trusts aka's app only when its code signature says so.
- **Headers helper:** a helper gets only the basic variables plus the server's own, not every key in your shell.

Fixes in 1.11.0
- **No crash on odd YAML:** a file of deeply nested brackets no longer crashes mcpock at launch, and odd files read fast.
- **Calmer panel:** Not checked rows and servers waiting for your OK are named in the footer, a Not checked row is a calm dash, the icon stays plain with no servers or while checking, and Needs you goes back to All once nothing needs you.
- **Faster, lighter checks:** remote checks finish within about 10 seconds, a server that drips its answer can't hold up the round, and quitting stops every server being checked.
- **Hermes and Goose:** `enabled: False`, `no` and `off` switch a server off in any spelling.
- **Grok:** Copy for Claude adds `enabled = true` for Grok.
- **Connect:** Claude Code added at project or local scope reads Connected, and running from the disk image warns you to move mcpock to Applications first.
- **Open config:** shows the full path and opens in a code editor instead of TextEdit when one is installed.
- **Widgets:** they no longer reload every minute for nothing, and grey out when mcpock stops updating them.
- **Windows:** Settings and What's New are normal windows, and What's New no longer takes your keyboard after an update.

mcpock 1.13.0. For macOS 26 or newer on Apple Silicon. Update from the app, or download it from mcpock.com.

New in 1.13.0
- **Next step:** every reason now has a line under it saying what to do, on the card, in `status.md` and in `mcpock_problems`, so you and your agent read the same thing.
- **A fix turns green by itself:** save a changed config and mcpock checks that server again within seconds, with no click. Only the servers the edit touched are started. Nothing is written, and with checks set to Manual it still waits for Refresh.

Simpler
- **The footer says two numbers:** "41 servers · 4 need you · 5 not checked". Hover it for the whole breakdown.
- **Three ways to copy:** Ask an agent, Copy errors, and Copy All Problems, which moved to a right-click on the panel's summary line. Copy Details is gone, because Ask an agent carries the same details.
- **Settings > General is shorter:** the status file moved to Settings > Connect, next to the helper that reads it. The counts are in the footer's tooltip.
- **Usage counts are one switch,** off for new installs. If you already had them on, they stay on.
- **Gone:** Export to a file, and the Hide scroll bars switch (scroll bars stay hidden).

Clearer words
- **First launch:** the welcome line says what mcpock does and what red means.
- **Grok Bot:** with an empty list it says Not visible here and where to look, instead of No servers yet.
- **Bad config:** an entry with no command or url says so, instead of Slow.
- **Quit after starting:** a server that dies after a good start says that, instead of Quit on start.
- **Timeouts:** the seconds shown are the time waited, not the time that was left.

Fixes
- **Shorter keys are masked:** a key of 16 to 31 plain letters and digits, or one in a URL path, no longer reaches the status files or the clipboard. So is a `${VAR}` secret a server repeats in its error.
- **Agents get the same picture as the panel:** a server lost in a Claude Code session now shows in `status.json`, `status.md` and the helper. A Not checked row is no longer listed as a problem there or on the widgets, and it no longer offers Ask an agent or Copy errors.
- **Tool names count as a server's own words:** they are fenced as untrusted in the helper's answers.
- **Allowed files ask again when they change more:** a file whose env values or header names change now asks for your OK again. Updating asks nothing for a file that didn't change.
- **Plain http warning:** it also covers a key in the URL, like `?token=` or `user:pass@`.
- **Escape on macOS 27:** it closes the panel with the default theme.
- **Needs you:** the panel goes back to All once the last problem clears while it is open. A search or the toggle closes the card of a row they took out of the list. The footer never reads all fine beside a lost server. Check again clears a lost row at once.
- **Agents tab:** an agent with a paused or waiting server no longer reads All fine, and its bar shows that part in grey.
- **Slow legacy SSE servers** that take over 3 s to name their endpoint read fine.
- **Needs <App> open:** a port that changed owner is noticed when the server fails.
- **Cleaner stops:** quitting during a check, or a login shell that takes too long, leaves nothing running.
